\# PROJECT CHARTER



\## Project Title

Cricket Match Scoreboard Application



\## 1. Project Overview

The Cricket Match Scoreboard Application is a console-based application developed using C++. The project is designed to record and manage cricket match scores, including runs, wickets, overs, and extras.



The application provides a simple menu-driven interface through which users can operate the scoreboard and view match information.



\## 2. Problem Statement

Manually maintaining cricket scores can be time-consuming and may lead to calculation errors. This project aims to provide a simple computerized solution for recording scores and displaying match results.



\## 3. Project Objectives

\- Develop a menu-driven cricket scoreboard.

\- Record team runs, wickets, and extras.

\- Calculate overs and run rate.

\- Manage first and second innings.

\- Display match results.

\- Apply Object-Oriented Programming concepts in C++.



\## 4. Project Scope

The application supports:

\- Two cricket teams.

\- Configurable match overs.

\- Recording runs and wickets.

\- Recording wides, no-balls, byes, and leg-byes.

\- Displaying the scoreboard.

\- Calculating run rate.

\- Displaying the match result.



\## 5. Technologies Used

\- Programming Language: C++

\- Compiler: GCC (g++)

\- Standard: C++17

\- Development Environment: Git Bash

\- Build Configuration: CMake (optional)



\## 6. Object-Oriented Programming Concepts

\- \*\*Encapsulation:\*\* Protecting class data using private members and public methods.

\- \*\*Inheritance:\*\* Batsman and Bowler inherit from Player.

\- \*\*Abstraction:\*\* Player is an abstract base class.

\- \*\*Polymorphism:\*\* Derived classes override the displayStats() function.



\## 7. Expected Outcome

The expected outcome is a working console-based cricket scoreboard that allows users to record match events, calculate team scores, manage innings, and display match results.



\## 8. Future Enhancements

\- Complete individual player statistics.

\- Support full cricket scoring rules.

\- Add player selection and team lineups.

\- Save match records in files.

\- Develop a graphical user interface.



\## 9. Conclusion

This project provides practical experience in C++ programming and Object-Oriented Programming. It demonstrates how multiple classes can work together to develop a simple cricket match management system.
